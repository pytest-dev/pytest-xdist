Fixed a ``KeyError`` with ``--dist=loadscope``/``--dist=loadfile`` when a worker died while another worker had not finished collecting. The dead worker's entry is now dropped from the scheduler's registered collections, so a still-collecting worker is no longer mistaken for a completed one (an ``INTERNALERROR``). A worker that has not reported its collection yet is also no longer handed work when another worker dies, which skipped reporting the crashed test.
